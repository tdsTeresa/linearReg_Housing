
<h2>📈 Descripción general:</h2>
<br>
<b>La regresión lineal es un modelo estadístico utilizado para simular una gama de predicciones entre variables y valores continuos.</b> En esta actividad se establece un modelo de regresión lineal en Python enfocado a predecir precios de viviendas. 
<h2>⚙️Tecnologías: </h2>
<br>
    • Python 3.10+<br>
    • Jupyter Notebook<br>
    • Pandas<br>
    • Numpy<br>
    • Matplotlib<br>
    • Seaborn<br>
    • Sklearn<br>
<br>

<h2>🖇️ Fuente: </h2><br>

[Housing Prices Dataset](https://www.kaggle.com/datasets/yasserh/housing-prices-dataset).
<br>
<br>

<h2>🧩 Variables:</h2
<br>
price, area, bedrooms, bathrooms, stories, mainroad, guestroom, basement, hotwaterheating, airconditioning, parking, prefarea, furnishingstatus<br>
<br>
<br>
<h2>📊 Actividades: </h2>
<br>
    • Preparación de modelo de ML.<br>
    • Definición de un modelo de regresión lineal.<br>
    • Análisis de elementos gráficos como Heatmap, histogramas, scatter plot.<br>
    • Transformación logarítmica y estandarización de datos.<br>
    • Evaluación del modelo mediante métricas MAE, MSE Y RMSE.<br>
<br>
<br>
<h2>⭐ Conclusiones del modelo: </h2>
<br> 
     • Explica el 66% la variabilidad de los precios.<br>
     • Se equivoca alrededor de 853 mil dólares.<br>
     • Se desvía en promedio 1.16 millones o el 24% respecto al precio real.<br>
     • La característica de los baños tiene la mayor relevancia en la determinación del precio.
